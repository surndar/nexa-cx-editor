
# Nexa CX Editor

Nexa CX Editor is a universal, browser-based video editing platform designed for multiple industries and creative workflows.

## Product Vision

The platform will support two editing approaches:

1. **Manual video editing:** Users can edit videos using timelines, tracks, layers, clips, text, audio, transitions, and effects.
2. **AI-powered video editing:** Future AI features will help users create and modify fully editable video projects.

## Development Roadmap

### Phase 1 — Basic Manual Video Editor
- Project and media management
- Multi-track timeline editing
- Video, image, text, and audio editing
- Basic transitions and effects
- Preview canvas
- Project saving and restoration
- MP4 export

### Phase 2 — Advanced Manual Editing
- Keyframe animation
- Masking and chroma key
- Motion tracking
- Advanced colour grading and audio editing

### Phase 3 — AI Integration
- Automatic subtitles
- AI editing assistant
- AI voiceovers and dubbing
- AI-powered video generation and editing

## Current Status

Project setup and technical planning are in progress. Feature implementation has not started.

## Development Approach

Nexa CX Editor follows a documentation-first development process. Features are specified and reviewed before implementation.
